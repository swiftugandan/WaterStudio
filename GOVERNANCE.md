# Governance

WaterStudio is a maintainer-led open-source project.

- **Maintainers** merge changes, cut releases and set direction. The founding maintainer is
  [@swiftugandan](https://github.com/swiftugandan). New maintainers are invited by existing maintainers after a
  sustained record of good contributions.
- **Decisions** are made in the open, on issues and pull requests. Significant technical decisions are recorded
  as architecture decision records in [docs/adr](docs/adr). Where consensus is not reached, the maintainers decide.
- **Numerical correctness** is not decided by vote: a change that moves results must be justified against the
  reference engine and the literature (see CONTRIBUTING.md).
- **Upstream first.** Fixes to code we forked (notably `engine/ws-hyd` from epanet-rs) are offered upstream.
