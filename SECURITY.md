# Security policy

WaterStudio runs on the user's device and is designed so that models never leave it unless the user chooses.
Please report anything that breaks that promise, or any other vulnerability, privately.

## Reporting

Use GitHub's [private vulnerability reporting](https://github.com/swiftugandan/WaterStudio/security/advisories/new).
Please do not open a public issue for a vulnerability. We aim to acknowledge reports within five working days.

## Supported versions

WaterStudio is pre-release; only `main` is supported.

## Scope

In scope: the engine (including crafted `.inp`, `.msx` and project files), the web app, the MCP server, and the
AI agent tools (including prompt injection through imported files or GIS attributes).
